# The Baniya Syn

A creative network concept for discovering AI-native creators, tracking campaigns, drafting creative briefs, and exploring illustrative creative-market signals.

**Affiliation / address:** Chandigarh University, Uttar Pradesh, India.

## Features
- Creator discovery with specialty and tool filters
- Sample creator profiles and portfolio previews
- Campaign pipeline and progress views
- Local, template-based creative brief generator
- Illustrative creative trend cards
- Email sign-in UI configured for Hatchable

## Run locally
Serve the `public/` directory with a static web server. The app uses `index.html`, `theme.css`, and `app.js`; `login.html` provides the sign-in UI. Authentication depends on Hatchable's hosted runtime.

## Transparency
Creator profiles, locations, rates, engagement figures, campaign budgets, and trend percentages are illustrative demo content, not verified market data. Brief generation currently creates a structured draft locally; it does not call an external AI model API.
